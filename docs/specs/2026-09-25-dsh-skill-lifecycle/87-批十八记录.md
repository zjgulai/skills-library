**批十八·仪器修复（重要）**：`version-consistency.mjs` 此前**不支持"单个技能目录"形态**——`--library` 指向候选目录时静默扫到 0 个技能、报"0 处"（**假绿**；批十七/十八的候选侧自检因此形同虚设）。修复：根目录含 SKILL.md 时视为单技能候选；**候选 0 或解析到 0 个技能 ⇒ stderr 警告 + exit 2**（空目录实测 exit 2）。修复后单候选扫描实测可检出（single-post 命中 1 处）；全库扫描 12 处不变。

**批十八·三处自伤（如实登记）**
1. **bash heredoc 写文件翻车**：一次命令里连写 5 个 momcozy 文件，`scenario-output.md` 混入拼接串、`acceptance-checklist.md` 未更新——**判者点名两处**，r123 前改用 Write 工具重写。教训：多文件写入一律用 Write，不拼 heredoc。
2. **README 历史注记写裸旧版本号**（3 处，见上）⇒ 版本扫描器计入；登记 P2。
3. **夹具误写进库内路径**（`技能库/.../tests/fixtures/`）：发现后立即移出、清理空目录，库内无残留（未造成差异，仍登记）。

**批十八·运行器间歇红（登记条件与签名，不做猜测性修复）**：`r121-r1` 与 `r124-r1` 各出现一次 node:test 级 `✖ failing tests`，但两记录均完整（attempts 全 settled、报告已写、批次组账本无异常），两次的 r2 均正常。签名：进程末尾报一次测试失败、无对应断言文本落盘。按既有纪律：登记条件与签名，不猜测修复；若后续 ≥3 次再启动猎捕。
