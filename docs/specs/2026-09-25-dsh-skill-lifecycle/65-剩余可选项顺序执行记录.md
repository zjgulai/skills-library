## ④ 优化回路脚本化：`trial-home/opt-run/opt-loop.mjs`

四个子命令（零请求可跑前两个与第四个）：

| 命令 | 作用 |
| --- | --- |
| `stage --skill <目录> --round <n>` | 冻结该技能为本轮材料（SKILL.md＋包内清单＋**合并的包内内容**），逐件记 sha256；**自动排除二进制/不透明件并登记**（上限 60k 字符） |
| `task --round <n>` | 生成本轮任务文件（**三件材料**：SKILL.md / 清单 / 合并内容——10 件会被"读不完"） |
| `run --round <n> --mode <capture\|wake-check\|live> --repeats <n>` | 打印**可直接执行**的 runner 命令与预算口径 |
| `read --round <n>` | 读该轮证据：结论、分数、issues 条目数、请求/tokens（零请求） |

用法与纪律写在脚本头部（材料是暂存副本、库只读、真实请求另给预算）。
**待补**：`run` 前自动清 stale run 目录（本轮踩过一次 `RUN_LOCKED`）。
