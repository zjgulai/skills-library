## 1. 为什么值得做（与已收敛的静态层的关系）

本项目所有真实运行里，**有区分度的维度一直是"界定率"那类边界行为**（`w02` 3/3 vs 0/3、

## 2. 探针 A（推荐先做）：同主题两版本的装载歧义

**背景**：你刚拍板 11 组「同主题两版本」**保持原样**（55 号 §7.1）。它们的描述文本同源改写、
相似度 1.0——**这正是静态层无法回答的问题**：模型看到两份几乎一样的描述，会不会装错、或者两份都装？

**对象**（同一对里选一份最像的）：
`content-strategy` ↔ `genspark-content-strategy`（英文、各 1 份、描述几乎逐字相同）。
若探针 A 顺利，再补一对人物视角（中文）做语言维度的对照。

**任务集**（8 题，预注册）：

| # | 类型 | 期望 |
| --- | --- | --- |
| 1–3 | 明确属于 `content-strategy`（例如"帮我规划下季度的内容选题方向"） | 应装入**且**只装入一份 |
| 4–5 | 需要 `genspark-social`/`social` 这类邻近技能的场景 | 不应装入这两份 strategy |
| 6 | 完全无关（如"帮我算这个表格的加权平均"） | 不装任何技能 |
| 7 | 只给"触发词"字面（如只说 "content ideas"） | 观察是否仅凭字面触发（**不预设期望**，只记录） |
| 8 | 应触发但材料不足（缺产品/渠道上下文） | 记录是否追问（**只记录**） |

**双臂**：`armed`（两份都装上）vs `none`（都不装）。不设"候选臂"——这一支不做版本比较。

**判据（预注册，跑前钉死）**：
1. 题 1–3：**装且只装一份**（选哪份都算通过；两份都装或都不装算失败）；
2. 题 4–6：**误装 = 0**；
3. 成本：每执行请求数 ≤ 8、tokens ≤ 40k（按 B 档实测 6.75 请求/31k 上浮 ~20%）；
4. 判分：独立判者 + 每臂 ≥2 条探针；未过校准则记 `inconclusive`（沿用 `blind-packet` 的规程）。

**预估成本**：8 题 × 2 臂 × 1 重复 = 16 执行 ≈ **100–110 请求 / 0.5M tokens**
（依据：B 档 16 执行实测 108 请求 / 497k tokens）。硬停建议 **150 请求 / 0.8M**。

## 3. 探针 B（可选，成本更高）：单个库技能的真实收益

从库里挑 **1 个**高价值技能，做 A4 式双臂（装 vs 不装）+ 植入缺陷任务集，问"装了以后交付质量是否更好"。
