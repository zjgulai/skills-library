# 20｜项目复盘与主目标（2026-09-26）

## 0. 第一优先需求（用户 2026-09-26 明确）

> 「能针对给定的一个 skill 做到优化、评估、迭代、与 DSH 适配的自动化。」

这条把建设重心从"把测量做准"推进到"把闭环跑起来"：给定一个技能 → 自动完成**优化（生成候选）→ 评估（对比原版）→ 迭代（有限次循环）→ DSH 适配（装进 DSH 并用起来）**，人在预算、契约变更与启用三类门上保留决定权。本复盘据此重新排序待办。

## 4. 关键缺口（必须随结论一起记住）

1. **技能原生加载未实测**：当前以"受限读取冻结副本"替代，不是 DSH 原生 `skill` 工具；`dsh-skill-filesystem` watcher 不收敛。
2. **终测已成立并已执行（2026-09-27）**：终测集 `w01` 已铸、隔离机检、判者校准，并完成两轮终测（`w01` 全通过；`w02` 第一波：非核验题候选 3/3 界定、原版 0/3）；`w01` 已烧、`w02` 尚余 4 题未用。**P1 批 A 已收口**：原版已足够（覆盖率 15/15 对 15/15），候选 not-promoted，未启用生产。
3. **判定已可独立复现（2026-09-27）**：盲包＋键分离＋gold-free 判据，独立 agent 盲判 10 条与预钉 token 门逐条一致；判者已有**反向探针＋校准集**且校准是轮次判定的前置门（未过校准只能记 inconclusive）；仍存：隔离开非强制、判者与产出同一模型族、探针集仅 5 条且单题。
4. **无统计量**：每题 1 次，成本只到 token 口径（无价格依据不估人民币）。
5. **材料缺陷**：`t5` 的"上半年营收 378 万"为非预期缺陷、金标漏登，复用前需修。

## 5. 拟建设：单技能自动化闭环 W1—W4

| 段 | 交付 | 是否需要真实请求 |
|---|---|---|
| **W1 候选区与差异记录** | 候选包结构（`candidates/<id>/`）、变更差异、修改理由、受影响范围、原版未变校验 | 否 |
| **W2 双臂比较运行器** | 原版/候选同题同预算的分臂运行、回归集、逐项比较报告（执行成功／任务成功／成本／介入次数） | 是（2×N 题） |
| **W3 迭代控制器与裁判** | 评估→改动→再评估的有限循环，停止条件（增益、预算、证据不足、风险），机械项脚本判 + 独立盲判开关 | W2 的基础上按轮追加 |
| **W4 DSH 适配与交付** | 技能原生加载补课、候选身份与加载证明、限定使用说明、启用/回退骨架（只到 `trial-home`，不碰生产岗位） | 否（加载验证可零出境） |

建议顺序：**W1 → W4 的加载补课 → W2 → W3**（先让"改"和"装"有位置，再花钱跑双臂）。全部需逐段授权；W2/W3 的真实请求预算单独拍板。

**进度（2026-09-26 更新）**：✅ W1 完成（`control/skill-candidate.mjs`，11 项测试）；✅ W4 的加载补课完成（`tests/w4-native-skill.test.mjs`，4 项；`watch:false`＋隔离家目录装配，原生 `skill` 工具返回冻结正文且身份可对）；✅ W2 双臂比较完成（候选 `t7-boundary-001` vs 冻结原版：目标题 t7 从「未界定范围」变为「明确界定」、尝试 6→2、tokens 27.9k→6.1k；回归题 t2/t6 无退化；35 次请求 / 155,586 tokens）；✅ W3 迭代控制器完成（`control/iteration-loop.mjs`：三条件停止＝主效应／回归／成本容差，外加 inconclusive 与 budget_stopped 两类非质量出口；14 项测试；已对 W2 真实数据判定 round-1 = accept）。闭环四段（W1 优化 → W2 评估 → W3 迭代控制 → W4 DSH 适配）全部落地。详见 [21-W1候选区与W4技能加载记录](21-W1候选区与W4技能加载记录.md)、[22-W2双臂比较记录](22-W2双臂比较记录.md)。

## 6. 结论（2026-09-26 原判 + 2026-09-27 更新）

**2026-09-26 原判**：没有完成整个生命周期的工程化沉淀——完成的是"P0 可信基础 + A1—A4 的测量链"，而 A5 候选生成、A6 对比迭代、A7 独立验收、P2 新建、P3 启用、P4 治理仍是纸面设计。

**2026-09-27 更新**：上述六个"纸面设计"全部落地为可运行、可复跑、各自带验证的工程件（见第 2 节刷新后的对照表与 [45-P0P4总盘点](45-P0P4总盘点.md)）。仍**不算"自动化完成"**的地方有三处，且都已定位：

1. **候选生成仍是半自动**——"从失败读数到具体改动"由独立 agent 人工产出，A5 归因自动化未做；
2. **真实第二轮迭代没走过**——控制器能判 `revise`，但"判了 revise 再改再评"的闭环从未真实跑过；
3. **三类场景一次都没真实跑过**——新技能链、带资源技能包、生产岗位；账本里目前只有一条真实处置。

另有一处性质不同：第 4 节列的"材料缺陷"（`t5` 金标漏登）与"无统计量"仍然成立，属任务集与度量口径的已知限制。
