# 36｜P3-1 启用计划与预览（2026-09-27）

按 [34-P2–P4 工程化计划](34P2P4工程化计划.md) 实施。**纯工程、零真实请求**；目标目录只限 `trial-home`。

## 交付物

`control/enablement.mjs`：

- **`planEnable({ allowedParent, root, skillId, candidate, previous })`** → 变更计划：
  - `preview`：**给人看的预览**——技能名、候选 id、`scope: 'trial-home-only'`、`firstInstall`、`added/replaced/removed`（只含**逻辑文件名 + 摘要**）、条数统计、装配声明（三条插件行，不含路径）。
  - 计划身份：`planDigest` 绑定 `{skillId, candidateId, 变更集, 已安装快照, 候选快照}`；另有 `changeDigest`/`targetDigest`/`candidateDigest` 供分项核对。
- **`verifyPlan()`**：apply 之前重新推导计划，`planDigest` 不一致即 `PLAN_CHANGED_SINCE_PREVIEW`。

**拒绝的情形**（都是可失败的检查）：

| 情形 | 错误码 |
|---|---|
| 目标不在 `allowedParent` 内 | `TARGET_OUT_OF_SCOPE` |
| 目标**经符号链接逃逸**（词法在内、realpath 在外） | `TARGET_OUT_OF_SCOPE` |
| 候选文件封存后被改/被删 | `CANDIDATE_FILE_CHANGED` / `CANDIDATE_FILE_MISSING` |
| 已安装状态与 `previous` 声明不符（漂移） | `INSTALLED_STATE_DRIFT` |
| 已安装树里出现符号链接/非普通文件 | `SYMLINK_NOT_ALLOWED` / `UNSUPPORTED_ENTRY` |
| 候选声明非法（空、`../`、非摘要、重复项、超限） | `INVALID_CANDIDATE` |
| 计划被改写后再 apply | `PLAN_CHANGED_SINCE_PREVIEW` |

## 实施中发现并修掉的一个真实漏洞

初版只用**词法包含**判断目标是否在允许目录内 → 形如 `<trial-home>/escape/x`（`escape` 是指向外部目录的符号链接）会被判为"在范围内"，且因为路径不存在而被当作**首次安装**放行。修法：对**最深的已存在祖先**取 `realpath` 后再判包含；该用例现已被测试钉住。

## 验证

`tests/enablement.test.mjs`，**9 项全绿**：首次安装只列新增；升级正确区分 replaced/removed；越界（含符号链接逃逸）被拒；候选封存后被改被拒；安装态漂移被拒；`verifyPlan` 通过/拒绝两条路径；声明校验；已安装树中的符号链接被拒；**预览零泄漏**（不含绝对路径、不含文件内容，只带摘要）＋计划摘要对同一状态稳定、对不同目标不同。

全量回归：**376 项通过**（此前 367）。
