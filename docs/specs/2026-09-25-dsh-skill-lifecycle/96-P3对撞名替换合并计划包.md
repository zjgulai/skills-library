## 3. 每对的三个候选动作（计划原件里逐对展开）

每对都给了 **replace / merge / rename** 三个候选＋考虑点＋推荐理由（见 JSON `pairs[].options/optionsNote`）。以第一对为例：

- **合并（推荐）**：以 A 为主体，把 B 的通用页面文案要点并入 A 的 references，B 退役；
- 替换：A 直接取 copywriting，B 退役（丢弃 B 的页面文案能力）；
- 改名并存：A 改用 `ecommerce-copywriting`，B 保留。
