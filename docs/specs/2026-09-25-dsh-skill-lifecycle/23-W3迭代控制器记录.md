## 1. 它解决什么

W2 的教训是：主效应达标 ≠ 可以宣布净收益——同一候选的成本项在重复间能翻 3 倍（候选 t7 尝试数 2／2／6，原版 6／5／3）。所以迭代循环的停止条件必须是**三条同时成立**，并把每条都写成可失败的判定：

1. **主效应**：目标题的证据门在候选臂达到预注册的命中数（默认 3 次重复里 ≥2 次）；
2. **回归**：所有回归题的证据门在候选臂仍然通过（原版臂自己不过门 ⇒ 视为完整性问题，而不是"候选更好"）；
3. **成本不劣化**：候选臂的中位尝试数与中位 tokens 相对原版臂的比值，必须落在容差内（默认 1.5 倍；**边界取等号算通过**）。

外加两类非质量出口：**证据不完整**（缺重复、任一 `incomplete`）→ `inconclusive`；**预算耗尽** → `budget_stopped`（不冒充质量失败）。

## 2. 模块与用法

`control/iteration-loop.mjs`：

- `collectObservations(records, { gateTokens })`：把 W2 形状的逐题记录收敛成观测（arm／taskId／repeat／gate／attempts／tokens／incomplete／reportWritten），**确定性排序**，证据门用**运行前钉死的 token 表**（直接取自 `a4/manifest.json` 的 `evidenceTokens`）而不是事后判读。
- `judgeRound({ round, observations, criteria, budgetExhausted })` → `{kind, reasons, metrics, inputsDigest, criteriaDigest}`；`kind ∈ {accept, revise, reject, inconclusive, budget_stopped}`；`reasons` 是机器可读码（`TARGET_NOT_MET`／`REGRESSION:<task>`／`COST_DEGRADED`／`ROUNDS_EXHAUSTED`／`EVIDENCE_INCOMPLETE`／`BASELINE_REGRESSION:<task>`／`BUDGET_EXHAUSTED`）。
- `recordRound({ root, verdict })`：把判定写到 `<root>/rounds/round-<n>.json`，**同轮次绝不覆盖**（`ROUND_EXISTS`）；每条判定都带 `inputsDigest`（它判的那批观测的摘要）与 `criteriaDigest`，事后替换证据或悄悄改判据都会被发现。
- CLI：`node skill-lifecycle/trial-home/a4/rounds.mjs <evidence-dir> --round <n> [--write]`（退出码 0 = accept，3 = 其他）。

判据（`defaultCriteria`，与 W2 记录一致）：目标 `t7-near-neighbor`、命中要求 2/3、回归 `t2-recompute`＋`t6-boundary`、成本容差 1.5×、最多 3 轮。

## 3. 测试（`tests/iteration-loop.test.mjs`，14 项）

覆盖：干净轮 accept；目标未达标 → revise；轮次用尽 → reject(`ROUNDS_EXHAUSTED`)；任一回归题掉门 → reject；**原版臂自己掉门 → inconclusive(`BASELINE_REGRESSION`)**（防止把基线失效当成候选胜利）；成本劣化 → revise / 轮次用尽 → reject；缺重复与 incomplete → inconclusive；预算耗尽 → budget_stopped；容差边界取等号通过、略超即不通过；判据与观测的字段级校验；`collectObservations` 的确定性；判定的只写一次与两轮各自留痕。

## 4. 对真实 W2 数据的复核（首轮判定）

```
node skill-lifecycle/trial-home/a4/rounds.mjs \
  skill-lifecycle/trial-home/evidence/w2-2026-09-26 --round 1 --write
→ kind: accept（reasons 空）
  目标命中 3/3（要求 ≥2）；尝试中位 5 vs 6（比 0.83）；tokens 中位 25,645 vs 27,163（比 0.94）
  inputsDigest 7ab80fd4…9466e；落盘 evidence/w2-2026-09-26/rounds/round-1.json
```

**读这条 verdict 时的三点注意**（写进记录以免误读）：
1. **accept 只表示"三条停止条件都成立"**，不表示"候选更好"——成本比 0.83／0.94 之所以在容差内，是三轮重复混合后的中位数；W2 第 6 节已撤回"候选更省"的说法，本条不构成翻案。
2. **它是"用更少证据做出的合法结论"**：3 次重复的命中门槛定在 2/3，这本身是预注册的宽松度，不是统计显著。
3. 判定绑定 `inputsDigest`；若以后往该证据目录补新记录，同一轮次的结论不会自动更新，必须作为新一轮重跑。
