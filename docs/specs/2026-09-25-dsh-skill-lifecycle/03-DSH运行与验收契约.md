# 03｜DSH 运行与验收契约

状态：目标契约待审阅；不表示 DSH 当前已具备所有控制能力。仅 DSH，不建立跨平台抽象。

## 1. 被验收对象

一次验收绑定：Skill 的完整内容身份、DSH 版本、模型与参数、岗位装配、工具和权限、任务集、裁判、环境初态。任一关键项变化，需要判断受影响证据是否应重跑；不能沿用一个笼统“兼容 DSH”的标签。

规划期选中试点和计算哈希，只证明所读文件的身份；执行期还要核对真实装载来源和内容。

## 2. 逐层验收

| 编号 | 验收层 | 必需证据 | 失败或未知的处理 |
|---|---|---|---|
| DSH-01 | 发现与作用域 | 目标测试岗位实际目录中存在该技能，来源可识别 | 不以技能中心可见或文件存在代替；先修装配，不改正文 |
| DSH-02 | 同名解析 | 实际胜出来源是本轮指定原版或候选 | 原候选分隔运行；不得因优先级误读另一份 |
| DSH-03 | 显式调用 | 相应调用策略允许时，用户手势或原生加载路径实际注入正确内容 | 本来禁用显式调用的技能应验证正确拒绝，不能为过测试强开 |
| DSH-04 | 自然选择 | 真实任务下加载记录及近邻非目标任务下的拒选／合理澄清 | 不能以回答提到名称或显式调用成功代替 |
| DSH-05 | 资源定位 | 使用资源时解析到当前包的正确内容，包外引用单独列明 | 无资源则该项不适用；新增资源后必须补验 |
| DSH-06 | 工具执行 | 原生工具调用与结果、身份、输入范围和实际产物 | 自述不算执行；工具错误与业务不合格分开 |
| DSH-07 | 业务结果 | 在规定对象和范围内满足业务验收 | 退出码零、生成文件或齐全模板不算充分证据 |
| DSH-08 | 权限边界 | 受控禁止操作实际被拒绝，原版／裁判不被写入 | 不进行真实破坏性探针；隔离达不到则阻断高后果实验 |
| DSH-09 | 恢复与预算 | 中断恢复后的对象一致、状态正确、预算累计、动作不错误重放 | 不能靠模型承诺或文件修改时间推断阶段已完成 |

## 3. 两类实验路径

### 3.1 内容能力实验

在明确加载正确版本之后测业务结果，隔离“能否选中”因素。原版和候选使用相同逻辑技能名，分别装配到互不污染的 DSH 运行。修改名称、扩大工具集、提供额外答案等都属于干预变化，不能只把收益归给正文。

### 3.2 自然选择及岗位集成实验

被测侧只收到正常用户请求，不带“请使用某技能”的提示。保留目标岗位相关的相邻技能和工具，记录实际模型可见目录及已加载内容。先在受控小集合定位问题，最终还要在有代表性的岗位装配中复验。

首轮本地报告与小型表格范围已确认，DSH接缝的只读核对已完成，见[P0调查](07-P0原生执行接缝与隔离方案.md)。具体测试岗位和模型尚未选定；执行前必须确认并冻结，不自行推定某 preset 就是生产代表。

## 4. 原版与候选隔离

- 使用同一逻辑技能名，在分开的运行区域或独立作用域装配，不能把两版同时暴露并靠名字暗示模型选择。
- 两侧数据、工具、授权和初态一致；工具结果中的历史文件、缓存、对话和 Git 历史也可能污染对照。
- 候选如果新增 references，原版不能读到候选资源；路径变更必须体现于内容清单。
- 内容相同但根目录不同也可能改变包外相对引用；基线移动后应检查引用语义是否保持。不能复制后自动补文件，再称“原版无改动”。
- 只读调查已找到Desktop原生create/prompt/follow/cancel等接缝，但访问隔离尚未证明，具体实现未选定；见[P0方案](07-P0原生执行接缝与隔离方案.md)。不猜测API、不调用会保存全局默认的模型切换入口来静默改变日常环境。
- 专用测试作用域的操作准入、预算与停止设计见[08-P0控制契约](08-P0读取预算与终止控制契约.md)。首版已由D10选择A，不开放任意代码或通用shell，原版与候选工具条件一致；受限环境结果不直接代表日常全工具岗位。实施步骤见[09-P0最小实现计划](09-P0最小实现计划.md)，尚未执行。

## 6. 必须新增验证、不得冒充已支持的能力

- 能否通过可维护接口创建干净被测运行，及如何识别实际正文和资源版本。
- 能否将优化者、受控裁判、目标执行者的读写权限分开；仅分会话不等于隔离。
- 原生事件里哪些字段可作为加载、执行、终止和用量证据，是否有缺失或延迟。
- 中断之后能否安全恢复，跨阶段产物如何提交，重复动作如何识别。
- 岗位装配与内容更新何时生效，有无缓存、热更新或上下文保留影响。

若某项暂无可靠接缝，记录阻塞和最小补齐方案。不得绕过审批、放宽权限或直接修改应用 bundle 来让试验看起来通过。

## 7. 本试点的适用范围

`validate-data` 当前只有一份 SKILL.md，无独立脚本、图片或参考目录。首轮可验证发现、选择、正文执行、局部计算、证据化报告、隔离与恢复。不能凭这个试点证明跨文件渐进读取、浏览器图表视觉验收、数据库连接或生产发布已经覆盖。

包外 `../../CONNECTORS.md` 缺失是已知静态事实。首轮若选择无需连接器的本地报告／数据路径，应标明排除了连接器分支；若运行时实际需要它，则停止并明确缺依赖。原版不得补齐后仍称未修改。候选是否修复引用要基于确认的目标与独立内容身份。
