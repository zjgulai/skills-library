## 3.5 观测：`~/.dsh/settings.yaml` 的 mtime 变为 2026-09-29 10:31（非我方写入）

收尾巡检发现 `~/.dsh/settings.yaml` mtime 从 **9-28 10:37 → 9-29 10:31**。排查：
- 本项目代码对该文件**只有读**（`grep` 全仓：`tests/*.test.mjs` 与 `trial-home/run-probe.mjs` 均为读取＋前后哈希比对，无任何写路径）；
- 文件内容里**没有**本次试用/优化相关的任何痕迹（`trial`/`opt-run`/`skill-lifecycle` 命中 0），顶层键全是 Desktop 应用设置（`dsh-desktop`/`ui-theme`/`llm-pi-ai`/`agent-presets`…）；
- 结论：**无法归因于本轮工作**，最可能是 **DSH Desktop 本体**在运行期保存设置所致（用户侧行为）。
**建议**：若你（或 Desktop）在 10:31 前后改过设置，符合预期；如非你所为，值得看一眼 Desktop 日志确认。
