## 状态词的含义

- **已确认**：用户明确同意的范围或方向。
- **设计建议**：本次存档提出的机制，等待审阅；不能当作用户已批准实现。
- **静态证据**：从文件或代码读取到的内容，不等于执行成功。
- **待验证**：需要真实 DSH 运行或测试才能确认。
- **未运行**：没有发生模型试验、脚本测试或生产部署，不提供模拟分数冒充结果。
