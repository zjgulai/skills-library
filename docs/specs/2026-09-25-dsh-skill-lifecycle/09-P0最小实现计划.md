## 2. 共同接口

可信宿主绑定`runId/batchId/sessionId/skillDigest/inputDigest/evaluatorDigest/environmentDigest/policyDigest`。字符串非空，摘要是64位十六进制。运行时完整匹配，不能由模型传参重新定义；真实sessionId确定前不得提交请求。

模型可见能力限定如下。

| 工具设计名 | 输入 | 输出 |
|---|---|---|
| `trial_read` | 宿主发放的`fileId`、非负`offset`、正`limit` | 内容片段、sha256、UTF-8总字节、是否截断 |
| `trial_compute` | 固定运算及表ID／列，不接受代码、URL或路径 | 结果、数据身份、命中行数和操作回执 |
| `trial_write_report` | `content`，没有输出路径参数 | 固定报告的sha256与字节数 |
| DSH原生`skill` | 本轮目录允许的name | 保留原生正文加载语义 |

不增加目录遍历、SQL／Python执行或任意文件名输出。`trial_read`按Unicode码点分页，UTF-8字节只用于限额和回执；允许读本run自己的最新报告，不可读其他运行。

## T03｜有限CSV与纯计算

**Files:** Create `control/table-compute.mjs`、`tests/table-compute.test.mjs`；Modify fixtures添加公开表格。

**Consumes:** T02允许的CSV文本快照，宿主映射tableId。

**Produces:** `parseCsv(text,limits)`返回深冻结的`headers/rows`；`limits`要求明确提供`maxBytes/maxRows/maxColumns/maxCellChars`，按UTF-8总字节、数据行数、列数和解码后Unicode码点限制，不靠上游默认兜底。`compute(request,tables,limits)`返回`operation/value/matchedRows/tableDigest/request/numericMode`，审计回执不带原始数据行。

支持标量`add/subtract/multiply/divide`（left/right），或表列`sum/mean/min/max/count/weighted_mean`（tableId/column/weightColumn/filters）。filter仅`{column,op:'eq'|'ne',value:string}`，条件数量受限；两类请求不混用，未知字段拒绝。`filters`缺省表示空列表，显式null／undefined或稀疏列表拒绝，不能悄悄扩大选择范围。`maxOperations`按一次调用检查，整批累计次数由后续控制层处理。
