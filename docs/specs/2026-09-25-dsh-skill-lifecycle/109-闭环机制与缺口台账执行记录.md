## 2. Q3 受控更新机制（已落地并验证）

**闸门与落位**（目标已存在且内容不同于计划清单时）：

- 不带 `expectTargetDigest` → 仍 `TARGET_CONFLICT`（§4 不放松）；摘要与当下目标不符 → `CONTENT_CHANGED`（结果里带 `targetDigest` 前 16 位）；目标缺失却带凭据 → `TARGET_MISSING`（防误判为新建）。
- dry-run 报 `planned-update`（不触盘、不建归档）；apply 顺序＝写 `tmp`（meta 增记 `replacedDigest`）→ 旧版整体移入 `技能库/_assembly-history/<name>/<digest12>/`（**装配根兄弟目录**，不入根内、不污染 Sage 发现面；同 digest 等价归档已存在时复用不搬家，结果记 `historyReused: true`）→ `rename` 落位 → 重读核对 → 失败回滚（`moved` 档移回、复用档复制还原）。
- 摘要口径：dir op 行在 `expectTargetDigest` 存在时并入第 6 字段（两侧同构）；无该字段的既有计划摘要不变——**batch-1 计划（`727b3a3e…`）原样复跑 173 `already-present`／0 拒**，即摘要口径向后兼容的实测证据（`q3-batch1-dryrun-backcompat.json`）。
- 平铺形态（C 组试点）不设更新路径，冲突仍拒收（未拍板不动）。

**验证**：执行器测试 **13/13**（新增 3 条：受控更新全链＋归档复用；闸门三态；等值优先且不建归档——含"归档必须在装配根之外"的断言）；全量回归 **554 项 / 552 过 / 0 红 / 2 跳过**（基线 551/549/2/0，＋3 全为本批；`q3-regression-summary.txt`）。
